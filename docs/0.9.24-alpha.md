# 0.9.24-alpha — 2026-11-10

Tag: `v0.9.24-alpha`

## Summary

Parity-focused release covering six service workstreams plus a Bazarr wanted parsing fix and CodeRabbit follow-ups.

## Changes

### Seerr
- Request moderation actions: approve/decline for Seerr media requests.

### Sonarr
- Per-episode file delete flow from series/season episode rows.

### Lidarr
- Album monitored toggle and track file delete actions.

### Prowlarr
- Indexer enable/disable controls and health status in the UI.

### SoulSync
- Actionable discover request flow and download cancellation controls.

### Navidrome
- Album drill-in and playlist screens, server-side search, starred/playlists browsing, and paging support.
- Follow-up fixes: preserve tab state and open artist rows.

### Bazarr
- Fixed wanted-entry parsing to handle the `episode_number` payload shape.
