# 0.9.22-alpha — 2026-11-09

Tag: `v0.9.22-alpha`

## Delete file from disk (new)

- Radarr movie detail gains a "Delete file from disk" button in the File
  section. Deletes the movie file only while keeping the movie entry,
  monitored state and history — so an upgrade can be grabbed and
  re-imported cleanly.
- Sonarr series detail: same button deletes all downloaded episode files
  while keeping the series.
- Confirm dialog; partial-failure handling; UI refreshes after.
- `RadarrMovie.movieFileId` and `SonarrEpisode.episodeFileId` parsed from
  `movieFile`/`episodeFile`.

## Updater fix

- In-app updater pointed at the private source repo (404). Now points at
  this public downloads repo. "Releases page" links updated.

## Verification

- `flutter analyze --fatal-infos` clean; `flutter test` 1257 passed.
- CodeRabbit: 0 findings.
- Device (Pixel 6): updater reports "You're up to date"; delete-file button
  renders; install timestamp matches build time.
