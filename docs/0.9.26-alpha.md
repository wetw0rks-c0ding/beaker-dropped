# 0.9.26-alpha — 2026-11-11

Prowlarr sorting and filtering for long result sets, plus a Bazarr providers fix.

## Added

- Prowlarr search results (both Prowlarr surfaces) can now be sorted by seeders, size, and age in either direction. Sort order is shared with the global Search tab (seeds by default, descending) and the Prowlarr section count label shows `Seeds ↓`/`Size ↑` etc. Sorting jumps the list back to the top.
- Media-type filter (All / TV / Movies; anime treated as TV) and protocol filter (All / Torrent / Usenet) for Prowlarr results, with a tinted filter icon, `N / total results` counts, empty-state message with a Clear filters action, and Tooltips (`Filter results` / `Sort results`).
- Shared `ProwlarrFilterMenuButton` widget; the global Search tab's duplicate sort menu items were consolidated into the shared `ProwlarrSortMenuButton`.

## Fixed

- Bazarr: providers returned by `/api/providers` (which only returns enabled providers and carries no `enabled` flag) no longer render as Disabled; a missing `enabled` field now means enabled, and an explicit false is still honored. Proven on device against opensubtitlescom and whisperai.
- Result count header on the Prowlarr releases screen only renders once results have actually loaded (no more "0 results" flash during search).

## Closed-loop verification

- Full suite 1385 passed; `flutter analyze --fatal-infos` clean.
- Pixel 6 proof (2026-11-11): Prowlarr search for "batman" returned 481 results; Movie filter → 116/481; TV → 354/481; Usenet → 86/481 (NZBgeek rows tagged `usenet`); sort seeds-descending order visually confirmed; filter icon tints when active.
- Bazarr Providers tab proven green/Enabled on device.
- No releases were grabbed and no indexers were modified.
