# 0.9.25-alpha — 2026-11-11

Add a real Sonarr add flow from missing/non-library title details.

## Added

- `Add Series` now opens an in-app sheet from Series detail when the title is not in the Sonarr library.
- Lookup uses `/api/v3/series/lookup?term=tvdb:<id>` and the existing TVDB-backed title context.
- Root folder and quality profile selection, monitored/all-seasons/search-on-add controls, and Sonarr add-options encoding.
- `/api/v3/rootfolder` discovery with tolerant parsing.
- Add-options monitor behavior preserves specials and supports unmatched season selection while leaving the requested series monitored.

## Error handling

- Malformed or empty TVDB lookup payloads no longer silently create the wrong series.
- Missing root folder and add-option data surface retryable states instead of trap empty sheets.
- Add-options monitor behavior is consistent with the selected monitor granularity.

## Closed-loop verification

- Flutter tests and `flutter analyze --fatal-infos` are clean on the release branch.
- Pixel 6 install proof: app reaches the add-series UI and shows root folder and quality profile; no destructive addition was performed during device proof.

## Release

- Android/iOS artifacts are built with dart defines for version and commit traceability.
